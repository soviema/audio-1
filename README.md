# Cahiers du Soviéma: audio, part 1

The audio files of the podcast «Cahiers du Soviéma», served by GitHub Pages at `https://soviema.github.io/audio-1/`.
The feed is <https://soviema.github.io/feed.xml> (repository `soviema/soviema.github.io`).

Podcast apps link to these files: never rename or replace a published file. GitHub Pages caps a site at 1 GB and a
file at 100 MB, so later episodes go to `audio-2` once this one nears 900 MB.
